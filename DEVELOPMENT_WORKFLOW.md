# Lumae Development Workflow

## Source-Control Requirement

After each completed Lumae task group, run the relevant validation, save a project checkpoint when a web-app change is ready for review, then commit and push the completed work to `github.com/BigLittleBusiness/lumae`.

Each delivery checklist must contain a concrete, verifiable Git task: confirm the commit hash, the GitHub push, and a clean worktree. Credentials are session-scoped and must not be stored in project files or committed to the repository.
